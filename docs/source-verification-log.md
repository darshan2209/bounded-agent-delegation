# Source verification log

Every empirical claim in the dissertation was checked against the publisher's own text,
then re-checked by a second, independent pass instructed to refute it. This log records
what each primary source actually says, so an examiner can re-run any row.

**Adversarial column:** `held up` means a second agent searched independently and could
not break the claim. `REFUTED` means it could. `not run` appears only where the first
pass returned UNVERIFIABLE, since there is nothing to refute.

Note that a REFUTED row does not always mean the dissertation was wrong. In several
cases the second pass overturned something the first pass had added, not something the
dissertation said. The evidence section below records which.

Verification dates: 13-14 September 2026 (round 1) and 20 September 2026 (round 2).
